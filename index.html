Abstract

Video style transfer remains challenging because preserving temporal consistency often suppresses the diversity and specificity of the reference style. UCVS addresses this tension with a training-free, two-stage framework that combines an image diffusion model with a pretrained text-to-video model.

Stage I introduces Temporal Improved Attention Distillation to produce a reference-faithful coarse stylized video. Stage II applies Flow-Guided Temporal Refinement, using inversion-free flow updates and reference key-value injection to construct the conditional difference required by FlowEdit. The resulting velocity difference suppresses residual flicker while retaining the style details established in Stage I, without training on stylized videos.

Method

UCVS is a training-free, two-stage framework that combines the broad style generalization of a pretrained image diffusion model with the temporal prior of a pretrained text-to-video model. Stage I uses Temporal Improved Attention Distillation to optimize a reference-faithful coarse stylized video through bidirectional Q/K/V correspondence and hierarchical keyframe propagation. Stage II applies Flow-Guided Temporal Refinement with a frozen T2V model. Because FlowEdit relies on the difference between source and target conditions, the source branch retains its native self-attention K/V features, whereas the target branch injects K/V features cached from the Stage-I result. Their velocity difference refines the video latent, suppressing residual flicker while preserving the transferred appearance and source motion.

In Stage I, Temporal Improved Attention Distillation transfers the reference appearance through bidirectional Q/K/V feature correspondence and hierarchical keyframe propagation, producing a style-faithful coarse video without stylized-video training. In Stage II, Flow-Guided Temporal Refinement adapts inversion-free FlowEdit updates to video. Native source K/V features and injected Stage-I K/V features construct the source-target conditional difference, whose velocity field guides temporally coherent refinement.

I

Style acquisition

Temporal Improved Attention Distillation

Extends Attention Distillation with bidirectional Q/K/V feature correspondence. Sparse keyframes are stylized first; hierarchical bisection then fills the remaining frames from nearby, already optimized anchors.

  • Frozen Stable Diffusion 1.5 backbone
  • Style, content, and temporal feature losses
  • No stylized-video training data
II

Temporal refinement

Flow-Guided Temporal Refinement

Adapts inversion-free FlowEdit updates to a frozen T2V model. Native source K/V features and injected Stage-I K/V features define the two conditions whose velocity difference guides temporally coherent refinement.

  • Pretrained video dynamics
  • Reference K/V injection
  • Default flow configuration
